# Multilingual AdaptiveCare — Phase 1

This is an **interface-only preview**. Hausa, Yoruba and Igbo navigation strings are draft translations, **not yet independently reviewed**. Clinical guidance remains in English. Do not present this as a translated medical service.

The language preference is stored in Streamlit session state (not a durable user account). Navigation uses stable English internal page IDs and localized display labels.

Before releasing translated health content or audio, implement content IDs, bilingual linguistic review, clinical approval, version-locked recordings, emergency-language fallback and privacy/accessibility testing.
