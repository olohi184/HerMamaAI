# HerMamaAI — educational prototype

Mobile-friendly Streamlit prototype by WechimAI Integrated Engineering & ICT Ltd.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important limitations
- Educational content only; not diagnosis, triage, therapy, or emergency response.
- No AI chatbot, accounts, or personal health data collection in this version.
- Provider directory is a placeholder pending verification.
- All health content and escalation messages require clinical review before pilot/public deployment.
- Obtain ethics review and appropriate consent before collecting participant data.
